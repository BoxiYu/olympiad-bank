# 历史提示凭证的题号时代与映射

`round-01` 至 `round-11` 的 `hints.json` 是不可改写的历史凭证，其中题号基于重编号前的
174 题态。映射在 2026-08-05 的 163 题快照上完成；后续新增题不改变这次题号转换，
因此不能把受影响记录的裸题号直接解释为现役题号。

受影响的 round 是 `round-02`、`round-03`、`round-04`、`round-08`、`round-09`、
`round-10`、`round-11`。下表给出这 7 个 round 中全部 21 条漂移记录的结论。
机器读取时使用同目录的 [`id-mapping-174-to-163.json`](id-mapping-174-to-163.json)；
其余 152 条历史记录仍与现库同号题逐字对应。

## 比对方法

1. 读取 11 个 `hints.json` 的全部 173 条记录，并把每条记录的三层提示分别作为完整的
   UTF-8 字符串，在当时 163 个 `problems/*/*.md` 文件中做全量精确搜索。
2. 只有三层提示都唯一命中同一个现役题文件，才记为“旧号 → 新号”；不做断句、空白归一化、
   相似度或语义匹配。
3. 三层提示在该快照均为零命中时，记为“已清退”。即使快照存在同号文件，也不据题号强行归属。
4. 2026-08-05 的复核结果为：152 条唯一命中同号题，11 条唯一命中新号题，10 条三层均零命中；
   没有部分命中或多义命中。

## 使用约定

- `hints.json` 保持原样，以保留历史凭证；读取方用 `(round, old_id)` 查映射，不能只用裸 `id`。
- `status: "active"` 的记录应转到 `new_id`；`status: "retired"` 的记录不得挂到现库同号题。
- 新的自动校验若消费这些历史文件，应把本映射作为题号时代转换层，而不是改写历史 JSON。
