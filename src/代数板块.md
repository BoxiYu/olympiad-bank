## 一、知识点树

### 1. 不等式
| 子类 | 典型考法 |
| --- | --- |
| **AM-GM（均值不等式）** | 把和式与积式互相转化，常用于"和固定求积最大/积固定求和最小"，以及给分式配对拆项。 |
| **Cauchy-Schwarz / Hölder** | 处理含根号或分母的和式，把 $\sum \frac{a_i^2}{b_i}$ 一步压到 $\frac{(\sum a_i)^2}{\sum b_i}$；Hölder 专治分母带 $\sqrt{\ }$ 或立方根的对称式。 |
| **SOS（配平方和）** | 把 $LHS-RHS$ 整理成 $\sum S_a(b-c)^2$ 的形式，再逐项判号，是三元对称不等式的通用兜底手段。 |
| **Schur 不等式** | $t\ge 0$ 时 $\sum a^t(a-b)(a-c)\ge 0$，用于 AM-GM 与 Cauchy 都"差一口气"的紧不等式，尤其是等号在 $a=b,c=0$ 处取到的题。 |
| **切线法 / Jensen** | 目标形如 $\sum f(a_i)\ge k$ 且约束为 $\sum a_i$ 固定时，在等号点作切线做逐项放缩；凸性成立时直接 Jensen。 |
| **排序与 Chebyshev** | 同序和最大、逆序和最小；配合轮换对称式做单调性比较。 |
| **归一化与齐次化** | 利用不等式的齐次性设 $a+b+c=1$ 或 $abc=1$，把约束吸收进式子。 |
| **SOS-Schur 之外的"打洞"** | 极值点在边界（某变量取端点）时，用"固定其余变量的一元函数"逐个把变量推到端点。 |

### 2. 函数方程
| 子类 | 典型考法 |
| --- | --- |
| **代入特殊值** | 令 $x=y=0$、$y=f(x)$、$x\to 1/x$ 等，先榨出 $f(0)$、$f(1)$ 与单点值。 |
| **单射/满射性** | 由 $f(a)=f(b)\Rightarrow a=b$ 或值域覆盖，把方程"消掉一层 $f$"。 |
| **Cauchy 型与半群结构** | 化为 $f(x+y)=f(x)+f(y)$ 或 $f(xy)=f(x)f(y)$，在正则性（单调/有界/正值）下定出线性或幂函数解。 |
| **不动点与迭代** | 研究 $f(f(x))$、$f^{(n)}(x)$，用不动点集合的结构限制解。 |
| **验证闭环** | 猜出候选解后必须回代验证，答案通常是 $f(x)=x$、$f(x)=1/x$、$f(x)=c-x$ 等少数几支。 |

### 3. 多项式
| 子类 | 典型考法 |
| --- | --- |
| **因式与根的结构** | 由若干取值相等/相反构造 $P(x)-c$ 的因式，反解首项系数。 |
| **恒等式定次数** | 由"两边最高次系数比较"卡死次数，再定常数项。 |
| **整值与整除性** | $a-b \mid P(a)-P(b)$，用于整系数多项式的取值限制。 |
| **对称多项式与牛顿恒等式** | 用幂和 $p_k$ 与初等对称式 $e_k$ 互推。 |

### 4. 数列与递推
| 子类 | 典型考法 |
| --- | --- |
| **进制型递推** | 形如 $a_{3n}=a_n,\ a_{3n+1}=a_n+1$，直接翻译成数位统计。 |
| **不动点/特征根法** | 线性递推与分式递推 $a_{n+1}=\frac{pa_n+q}{ra_n+s}$ 的标准化。 |
| **构造不变量** | 找出 $a_{n+1}T_n=a_nT_{n-1}$ 一类守恒量，把递推一次性求解。 |
| **求和放缩** | 部分和的上下界估计，常配合裂项与 Abel 变换。 |

### 5. 复数与三角
| 子类 | 典型考法 |
| --- | --- |
| **复数的几何意义** | 垂直 $\Leftrightarrow$ 商为纯虚数，共线 $\Leftrightarrow$ 商为实数。 |
| **单位根与对称** | $\omega^n=1$ 求和、模长与辐角约束下的整点问题。 |
| **三角恒等变形** | 积化和差、辅助角、$\sin^2\alpha+\cos^2(\alpha+30^\circ)+\sin\alpha\cos(\alpha+30^\circ)=\tfrac34$ 一类"隐藏常数"恒等式。 |
| **对称幂和** | 设 $u=\sin^2x\cos^2 x$，把 $\sin^{2k}x+\cos^{2k}x$ 递推成 $u$ 的多项式。 |

### 6. 根与系数（Vieta）
| 子类 | 典型考法 |
| --- | --- |
| **对称和反解** | 由 $\sum x_i,\ \sum x_ix_j$ 直接算目标对称式，避免解方程。 |
| **复因式配对** | $\prod(x_i^2+1)=\prod(x_i-i)(x_i+i)=P(i)P(-i)$ 这类"整体代入"技巧。 |
| **根的分布** | 判别式、韦达 + 区间条件确定参数范围。 |

### 7. 代数变换技巧
| 子类 | 典型考法 |
| --- | --- |
| **整体换元** | 把重复出现的块设为新变量，把高次/含根式方程降为二次。 |
| **对称化与轮换** | 设 $s=x+y,\ p=xy$，或用轮换对称性只讨论 $a\ge b\ge c$。 |
| **配方与恒等式凑形** | 把 $\frac{x}{x-1}$ 类分式设为 $a$ 并挖出 $abc=(a-1)(b-1)(c-1)$ 的隐藏关系。 |
| **对数与指数运算律** | 换底、$\log_{b^k}a^m=\frac mk\log_b a$，把连乘连加的对数式线性化。 |

## 二、题目条目

### A-001｜九个数的和
- **出处**：华罗庚金杯少年数学邀请赛 2018 年香港赛区决赛 小中组 第 2 题
- **难度**：★1
- **知识点**：平均数 / 整体设元
- **题面**：若将 9 个数按照从小到大的顺序排成一列，中间的数恰是这 9 个数的平均数，前 5 个数的平均数是 $40$，后 5 个数的平均数是 $60$，则这 9 个数的和为 ______。
- **答案**：$450$
- **解法要点**：前 5 个数之和为 $200$，后 5 个数之和为 $300$，两段重叠在第 5 个数上，故 $S+a_5=500$。又 $a_5=\frac S9$，解 $\frac{10}{9}S=500$ 即得。
- **来源**：https://hkhcm.org/wp-content/uploads/2018/12/2018_A.pdf

### A-002｜苹果和梨
- **出处**：华罗庚金杯少年数学邀请赛 2018 年香港赛区决赛 小中组 第 9 题
- **难度**：★1
- **知识点**：一次方程组 / 设元列式
- **题面**：有一些苹果和梨。如果按每 1 个苹果 2 个梨分堆，梨分完时还剩 5 个苹果；如果按每 3 个苹果 5 个梨分堆，苹果分完了还剩 5 个梨。那么梨有多少个？
- **答案**：$80$ 个梨（此时苹果 $45$ 个）
- **解法要点**：第一种分法设堆数 $k$，得苹果 $=k+5$、梨 $=2k$；第二种设堆数 $m$，得苹果 $=3m$、梨 $=5m+5$。联立 $k+5=3m,\ 2k=5m+5$ 解出 $m=15$。
- **来源**：https://hkhcm.org/wp-content/uploads/2018/12/2018_A.pdf

### A-003｜四数两两平均
- **出处**：AMC 8 2022 Problem 16
- **难度**：★1
- **知识点**：线性方程组 / 消元
- **题面**：一行写着四个数。前两个数的平均数是 $21$，中间两个数的平均数是 $26$，最后两个数的平均数是 $30$。那么第一个数与最后一个数的平均数是多少？
  $\textbf{(A) } 24\quad \textbf{(B) } 25\quad \textbf{(C) } 26\quad \textbf{(D) } 27\quad \textbf{(E) } 28$
- **答案**：$\textbf{(B) } 25$
- **解法要点**：记四数为 $a,b,c,d$，则 $a+b=42,\ b+c=52,\ c+d=60$。作交错求和 $(a+b)-(b+c)+(c+d)=a+d=50$，无需解出各数。
- **来源**：https://artofproblemsolving.com/wiki/index.php/2022_AMC_8_Problems/Problem_16

### A-004｜填空里的正整数个数
- **出处**：AMC 8 2022 Problem 13
- **难度**：★1
- **知识点**：一次不定方程 / 整数解计数
- **题面**：有多少个正整数可以填入下面这句话的空格中？"一个正整数比另一个正整数的 $2$ 倍多 ______，且这两个数之和是 $28$。"
  $\textbf{(A) } 6\quad \textbf{(B) } 7\quad \textbf{(C) } 8\quad \textbf{(D) } 9\quad \textbf{(E) } 10$
- **答案**：$\textbf{(D) } 9$
- **解法要点**：设较小数为 $n$，较大数为 $28-n$，空格中的数 $d=(28-n)-2n=28-3n$。要求 $n\ge 1$ 且 $d\ge 1$（均为正整数），得 $n=1,2,\dots,9$。
- **来源**：https://artofproblemsolving.com/wiki/index.php/2022_AMC_8_Problems/Problem_13

### A-005｜两个底数的对数方程
- **出处**：AMC 12A 2018 Problem 14
- **难度**：★2
- **知识点**：对数运算律 / 换底
- **题面**：方程 $\log_{3x} 4=\log_{2x} 8$ 的解（其中 $x$ 是正实数且 $x\neq \frac13,\ x\neq\frac12$）可写成 $\frac pq$，其中 $p,q$ 是互质的正整数。求 $p+q$。
  $\textbf{(A) } 5\quad \textbf{(B) } 13\quad \textbf{(C) } 17\quad \textbf{(D) } 31\quad \textbf{(E) } 35$
- **答案**：$\textbf{(D) } 31$（即 $x=\tfrac{4}{27}$）
- **解法要点**：设公共值为 $t$，则 $(3x)^t=4=2^2$、$(2x)^t=8=2^3$。两式指数比为 $2:3$，故 $(3x)^3=(2x)^2$，得 $27x^3=4x^2$。
- **来源**：https://artofproblemsolving.com/wiki/index.php/2018_AMC_12A_Problems/Problem_14

### A-006｜完全可加函数
- **出处**：AMC 10A 2021 Problem 18
- **难度**：★2
- **知识点**：函数方程 / 完全可加性
- **题面**：设 $f$ 是定义在正有理数集上的函数，满足对任意正有理数 $a,b$ 有 $f(a\cdot b)=f(a)+f(b)$，且对每个素数 $p$ 有 $f(p)=p$。下列哪个数 $x$ 使得 $f(x)<0$？
  $\textbf{(A) } \frac{17}{32}\quad \textbf{(B) } \frac{11}{16}\quad \textbf{(C) } \frac79\quad \textbf{(D) } \frac76\quad \textbf{(E) } \frac{25}{11}$
- **答案**：$\textbf{(E) } \frac{25}{11}$（$f\!\left(\tfrac{25}{11}\right)=-1$）
- **解法要点**：由可加性推出 $f\!\left(\tfrac mn\right)=f(m)-f(n)$，且 $f\!\left(\prod p_i^{e_i}\right)=\sum e_ip_i$。于是把每个选项按素因数分解逐一算"权重和"之差即可。
- **来源**：https://artofproblemsolving.com/wiki/index.php/2021_AMC_10A_Problems/Problem_18

### A-007｜两个对数求和之积
- **出处**：AMC 12A 2021 Problem 14
- **难度**：★2
- **知识点**：对数运算律 / 求和公式
- **题面**：求 $\left(\sum_{k=1}^{20}\log_{5^k}3^{k^2}\right)\cdot\left(\sum_{k=1}^{100}\log_{9^k}25^k\right)$ 的值。
  $\textbf{(A) } 21\quad \textbf{(B) } 100\log_5 3\quad \textbf{(C) } 200\log_3 5\quad \textbf{(D) } 2200\quad \textbf{(E) } 21000$
- **答案**：$\textbf{(E) } 21000$
- **解法要点**：$\log_{5^k}3^{k^2}=k\log_5 3$，第一个和为 $210\log_5 3$；$\log_{9^k}25^k=\log_9 25=\log_3 5$，第二个和为 $100\log_3 5$。两者相乘时 $\log_5 3\cdot\log_3 5=1$ 抵消。
- **来源**：https://artofproblemsolving.com/wiki/index.php/2021_AMC_12A_Problems/Problem_14

### A-008｜隐藏常数的三角恒等式
- **出处**：2021 年全国高中数学联赛 浙江省预赛 第 2 题
- **难度**：★2
- **知识点**：三角恒等变形 / 降幂公式
- **题面**：计算 $\sin^2 20^\circ+\cos^2 50^\circ+\sin 20^\circ\cos 50^\circ$ 的值。
- **答案**：$\dfrac34$
- **解法要点**：用 $\sin^2\theta=\frac{1-\cos 2\theta}{2}$、$\cos^2\theta=\frac{1+\cos2\theta}{2}$ 降幂，再对 $\sin20^\circ\cos50^\circ$ 积化和差；三处 $\cos40^\circ,\cos100^\circ,\sin70^\circ$ 恰好互相抵消。这是恒等式 $\sin^2\alpha+\cos^2(\alpha+30^\circ)+\sin\alpha\cos(\alpha+30^\circ)=\frac34$ 的特例。
- **来源**：https://artofproblemsolving.com/downloads/printable_post_collections/2393511.pdf

### A-009｜三进制数位递推
- **出处**：2021 年全国高中数学联赛 浙江省预赛 第 6 题
- **难度**：★2
- **知识点**：数列与递推 / 进制翻译
- **题面**：数列 $\{a_n\}$ 满足 $a_0=0,\ a_1=a_2=1$，且对一切 $n\ge 1$ 有 $a_{3n}=a_n,\ a_{3n+1}=a_{3n+2}=a_n+1$。求 $a_{2021}$。
- **答案**：$6$
- **解法要点**：递推按 $n$ 的三进制末位分类：末位为 $0$ 不加，末位为 $1$ 或 $2$ 加 $1$。故 $a_n$ 就是 $n$ 的三进制表示中非零数位的个数。$2021=(2202122)_3$，非零数位共 $6$ 个。
- **来源**：https://artofproblemsolving.com/downloads/printable_post_collections/2393511.pdf

### A-010｜带根号的整体换元
- **出处**：AIME 1983 Problem 3
- **难度**：★3
- **知识点**：代数变换技巧 / 整体换元 / 韦达定理
- **题面**：方程 $x^2+18x+30=2\sqrt{x^2+18x+45}$ 的所有实根之积是多少？
- **答案**：$20$
- **解法要点**：令 $y=x^2+18x+30$，则根号内为 $y+15$，方程化为 $y=2\sqrt{y+15}$，平方得 $y^2-4y-60=0$，$y=10$ 或 $y=-6$（后者不满足左边非负，舍去）。回代得 $x^2+18x+20=0$，由韦达定理根之积为 $20$（判别式 $>0$ 保证两根都是实根）。
- **来源**：https://artofproblemsolving.com/wiki/index.php/1983_AIME_Problems/Problem_3

### A-011｜两条抛物线过同两点
- **出处**：AIME 2022 I Problem 1
- **难度**：★3
- **知识点**：多项式 / 待定系数
- **题面**：二次多项式 $P(x)$ 与 $Q(x)$ 的首项系数分别为 $2$ 和 $-2$，两者的图象都经过点 $(16,54)$ 和 $(20,53)$。求 $P(0)+Q(0)$。
- **答案**：$116$
- **解法要点**：考虑 $R(x)=P(x)+Q(x)$，首项系数相消，$R$ 至多一次；由 $R(16)=108,\ R(20)=106$ 定出这条直线，再取 $x=0$。
- **来源**：https://artofproblemsolving.com/wiki/index.php/2022_AIME_I_Problems/Problem_1

### A-012｜两个对数约束
- **出处**：AIME 2023 I Problem 2
- **难度**：★3
- **知识点**：对数运算律 / 换元
- **题面**：正实数 $b\neq 1$ 与 $n$ 满足方程 $\sqrt{\log_b n}=\log_b\sqrt n$ 和 $b\cdot\log_b n=\log_b(bn)$。已知 $n=\frac jk$，其中 $j,k$ 是互质的正整数，求 $j+k$。
- **答案**：$881$（即 $n=\frac{625}{256}$）
- **解法要点**：设 $t=\log_b n$。第一式给出 $\sqrt t=\frac t2$，故 $t=4$（$t=0$ 会使第二式矛盾）。第二式化为 $bt=1+t$，得 $b=\frac54$，于是 $n=b^4$。
- **来源**：https://artofproblemsolving.com/wiki/index.php/2023_AIME_I_Problems/Problem_2

### A-013｜十次幂到十二次幂
- **出处**：AIME 2019 I Problem 8
- **难度**：★3
- **知识点**：三角 / 对称幂和递推
- **题面**：设实数 $x$ 满足 $\sin^{10}x+\cos^{10}x=\dfrac{11}{36}$。若 $\sin^{12}x+\cos^{12}x=\dfrac mn$，其中 $m,n$ 是互质的正整数，求 $m+n$。
- **答案**：$67$（即 $\dfrac{13}{54}$）
- **解法要点**：令 $u=\sin^2x\cos^2x$，记 $S_k=\sin^{2k}x+\cos^{2k}x$，由 $\sin^2x+\cos^2x=1$ 得递推 $S_k=S_{k-1}-u\,S_{k-2}$。用 $S_5=\frac{11}{36}$ 解出 $u$，再推一步得 $S_6$。
- **来源**：https://artofproblemsolving.com/wiki/index.php/2019_AIME_I_Problems/Problem_8

### A-014｜复数直角三角形
- **出处**：AIME 2019 I Problem 12
- **难度**：★3
- **知识点**：复数 / 垂直条件
- **题面**：设 $f(z)=z^2-19z$。存在复数 $z$，使得 $z,\ f(z),\ f(f(z))$ 构成一个在 $f(z)$ 处为直角的直角三角形（顶点为这三个复数在复平面上的对应点）。其中一个这样的 $z$ 可以写成 $m+\sqrt n+11i$ 的形式，$m,n$ 为正整数。求 $m+n$。
- **答案**：$230$（$z=9+\sqrt{221}+11i$）
- **解法要点**：直角条件等价于 $\dfrac{f(f(z))-f(z)}{z-f(z)}$ 为纯虚数。化简后归结为 $(z-19)(z+1)$ 是纯虚数；代入 $z=a+11i$ 比较实部得 $a^2-18a-140=0$。
- **来源**：https://artofproblemsolving.com/wiki/index.php/2019_AIME_I_Problems/Problem_12

### A-015｜六点等绝对值的三次多项式
- **出处**：AIME 2015 I Problem 10
- **难度**：★3
- **知识点**：多项式 / 因式构造
- **题面**：设 $f(x)$ 是实系数三次多项式，满足 $|f(1)|=|f(2)|=|f(3)|=|f(5)|=|f(6)|=|f(7)|=12$。求 $|f(0)|$。
- **答案**：$72$
- **解法要点**：六个点上取值只能是 $\pm 12$，而三次多项式与水平线至多交于 $3$ 点，故取 $+12$ 与取 $-12$ 的点各恰好 $3$ 个。写 $f(x)=a(x-r_1)(x-r_2)(x-r_3)+12$，用另外三点定出可行分组与 $a$。
- **来源**：https://artofproblemsolving.com/wiki/index.php/2015_AIME_I_Problems/Problem_10

### A-016｜四根成等差的复合二次
- **出处**：2021 年全国高中数学联赛 浙江省预赛 第 11 题
- **难度**：★3
- **知识点**：多项式 / 根与系数 / 等差数列
- **题面**：函数 $f(x)=x^2+ax+b$ 有两个不同的零点。若 $f(x^2+2x-1)=0$ 有四个不同的零点 $x_1<x_2<x_3<x_4$ 且它们成等差数列，求 $a-b$ 的取值范围。
- **答案**：$a-b\le \dfrac{25}{9}$，即取值范围为 $\left(-\infty,\ \dfrac{25}{9}\right]$
- **解法要点**：设 $f$ 的两根为 $r>s$。$x^2+2x-1=t$ 即 $(x+1)^2=t+2$，故四根关于 $x=-1$ 对称，形如 $-1\pm p,\ -1\pm q$（$p=\sqrt{r+2}>q=\sqrt{s+2}>0$）。等差条件给出 $p=3q$，即 $r=9s+16$；再由韦达定理把 $a-b$ 写成 $s$ 的二次函数 $-9s^2-26s-16$（$s>-2$），配方求最大值。
- **来源**：https://artofproblemsolving.com/downloads/printable_post_collections/2393511.pdf

### A-017｜三个根式方程组
- **出处**：AIME 2022 I Problem 15
- **难度**：★3
- **知识点**：代数变换技巧 / 三角代换
- **题面**：设正实数 $x,y,z$ 满足方程组

  已知 $\left[(1-x)(1-y)(1-z)\right]^2=\dfrac mn$，其中 $m,n$ 互质，求 $m+n$。

### A-018｜三分式根号不等式

### A-020｜连乘幂不等式
- **出处**：IMO 2012 Problem 2
- **难度**：★4
- **知识点**：不等式 / AM-GM 拆项
- **题面**：设 $a_2,a_3,\dots,a_n$ 为正实数，满足 $a_2a_3\cdots a_n=1$。证明：
  $$(a_2+1)^2(a_3+1)^3\cdots(a_n+1)^n>n^n .$$
- **答案**：不等式严格成立。
- **解法要点**：对每个 $k$ 用加权 AM-GM：把 $a_k+1$ 写成 $a_k+\underbrace{\tfrac1{k-1}+\cdots+\tfrac1{k-1}}_{k-1\ \text{项}}$，得 $(a_k+1)^k\ge \frac{k^k}{(k-1)^{k-1}}a_k$。全部相乘，右端出现望远镜积 $\prod\frac{k^k}{(k-1)^{k-1}}=n^n$，而 $\prod a_k=1$。等号需 $a_k=\frac1{k-1}$ 同时成立，与约束矛盾，故为严格不等号。
