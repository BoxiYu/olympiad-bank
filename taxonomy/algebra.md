# 代数板块 · 知识点树

### 1. 不等式
| 子类 | 典型考法 |
| --- | --- |
| **AM-GM（均值不等式）** | 把和式与积式互相转化，常用于"和固定求积最大/积固定求和最小"，以及给分式配对拆项。 |
| **Cauchy-Schwarz / Hölder** | 处理含根号或分母的和式，把 $\sum \frac{a_i^2}{b_i}$ 一步压到 $\frac{(\sum a_i)^2}{\sum b_i}$；Hölder 专治分母带 $\sqrt{\ }$ 或立方根的对称式。 |
| **SOS（配平方和）** | 把 $LHS-RHS$ 整理成 $\sum S_a(b-c)^2$ 的形式，再逐项判号，是三元对称不等式的通用兜底手段。 |
| **Schur 不等式** | $t\ge 0$ 时 $\sum a^t(a-b)(a-c)\ge 0$，用于 AM-GM 与 Cauchy 都"差一口气"的紧不等式，尤其是等号在 $a=b,c=0$ 处取到的题。 |
| **切线法 / Jensen** | 目标形如 $\sum f(a_i)\ge k$ 且约束为 $\sum a_i$ 固定时，在等号点作切线做逐项放缩；凸性成立时直接 Jensen。 |
| **排序与 Chebyshev** | 同序和最大、逆序和最小；配合轮换对称式做单调性比较。 |
| **归一化与齐次化** | 利用不等式的齐次性设 $a+b+c=1$ 或 $abc=1$，把约束吸收进式子。 |
| **SOS-Schur 之外的"打洞"** | 极值点在边界（某变量取端点）时，用"固定其余变量的一元函数"逐个把变量推到端点。 |

### 2. 函数方程
| 子类 | 典型考法 |
| --- | --- |
| **代入特殊值** | 令 $x=y=0$、$y=f(x)$、$x\to 1/x$ 等，先榨出 $f(0)$、$f(1)$ 与单点值。 |
| **单射/满射性** | 由 $f(a)=f(b)\Rightarrow a=b$ 或值域覆盖，把方程"消掉一层 $f$"。 |
| **Cauchy 型与半群结构** | 化为 $f(x+y)=f(x)+f(y)$ 或 $f(xy)=f(x)f(y)$，在正则性（单调/有界/正值）下定出线性或幂函数解。 |
| **不动点与迭代** | 研究 $f(f(x))$、$f^{(n)}(x)$，用不动点集合的结构限制解。 |
| **验证闭环** | 猜出候选解后必须回代验证，答案通常是 $f(x)=x$、$f(x)=1/x$、$f(x)=c-x$ 等少数几支。 |

### 3. 多项式
| 子类 | 典型考法 |
| --- | --- |
| **因式与根的结构** | 由若干取值相等/相反构造 $P(x)-c$ 的因式，反解首项系数。 |
| **恒等式定次数** | 由"两边最高次系数比较"卡死次数，再定常数项。 |
| **整值与整除性** | $a-b \mid P(a)-P(b)$，用于整系数多项式的取值限制。 |
| **对称多项式与牛顿恒等式** | 用幂和 $p_k$ 与初等对称式 $e_k$ 互推。 |

### 4. 数列与递推
| 子类 | 典型考法 |
| --- | --- |
| **进制型递推** | 形如 $a_{3n}=a_n,\ a_{3n+1}=a_n+1$，直接翻译成数位统计。 |
| **不动点/特征根法** | 线性递推与分式递推 $a_{n+1}=\frac{pa_n+q}{ra_n+s}$ 的标准化。 |
| **构造不变量** | 找出 $a_{n+1}T_n=a_nT_{n-1}$ 一类守恒量，把递推一次性求解。 |
| **求和放缩** | 部分和的上下界估计，常配合裂项与 Abel 变换。 |

### 5. 复数与三角
| 子类 | 典型考法 |
| --- | --- |
| **复数的几何意义** | 垂直 $\Leftrightarrow$ 商为纯虚数，共线 $\Leftrightarrow$ 商为实数。 |
| **单位根与对称** | $\omega^n=1$ 求和、模长与辐角约束下的整点问题。 |
| **三角恒等变形** | 积化和差、辅助角、$\sin^2\alpha+\cos^2(\alpha+30^\circ)+\sin\alpha\cos(\alpha+30^\circ)=\tfrac34$ 一类"隐藏常数"恒等式。 |
| **对称幂和** | 设 $u=\sin^2x\cos^2 x$，把 $\sin^{2k}x+\cos^{2k}x$ 递推成 $u$ 的多项式。 |

### 6. 根与系数（Vieta）
| 子类 | 典型考法 |
| --- | --- |
| **对称和反解** | 由 $\sum x_i,\ \sum x_ix_j$ 直接算目标对称式，避免解方程。 |
| **复因式配对** | $\prod(x_i^2+1)=\prod(x_i-i)(x_i+i)=P(i)P(-i)$ 这类"整体代入"技巧。 |
| **根的分布** | 判别式、韦达 + 区间条件确定参数范围。 |

### 7. 代数变换技巧
| 子类 | 典型考法 |
| --- | --- |
| **整体换元** | 把重复出现的块设为新变量，把高次/含根式方程降为二次。 |
| **对称化与轮换** | 设 $s=x+y,\ p=xy$，或用轮换对称性只讨论 $a\ge b\ge c$。 |
| **配方与恒等式凑形** | 把 $\frac{x}{x-1}$ 类分式设为 $a$ 并挖出 $abc=(a-1)(b-1)(c-1)$ 的隐藏关系。 |
| **对数与指数运算律** | 换底、$\log_{b^k}a^m=\frac mk\log_b a$，把连乘连加的对数式线性化。 |
