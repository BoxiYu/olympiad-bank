# N-033｜$n!=a^{n-1}+b^{n-1}+c^{n-1}$ 的有限性

## 题面

证明：方程 $n!=a^{n-1}+b^{n-1}+c^{n-1}$ 在正整数中只有有限多组解。

## 答案

结论成立（解的组数有限）。

## 解法要点

先由 $n!$ 的大小反推出 $\max(a,b,c)$ 与 $n$ 之间的紧约束。再取一个介于 $n/2$ 与 $n$ 之间的素数 $p$（Bertrand），则 $p\mid n!$；用费马小定理分析 $a^{n-1}+b^{n-1}+c^{n-1} \bmod p$ 只能取少数几个值，从而排除 $n$ 充分大的情形。
