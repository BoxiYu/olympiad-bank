# N-008｜$2^n\pm1$ 与 $7$

## 题面

(a) 求所有使 $2^n-1$ 被 $7$ 整除的正整数 $n$；(b) 证明：不存在正整数 $n$ 使 $2^n+1$ 被 $7$ 整除。

## 答案

(a) 恰为 $3\mid n$ 的那些 $n$；(b) 结论成立。

## 解法要点

$2^n \bmod 7$ 以 $2,4,1$ 三步为周期（即 $\mathrm{ord}_7(2)=3$）。(a) 需 $2^n\equiv 1$；(b) 需 $2^n\equiv 6$，而 $6$ 不在 $\{1,2,4\}$ 中。
