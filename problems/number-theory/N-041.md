# N-041｜互素判据函数方程与根基

## 题面

记 $\mathbb Z_{>0}$ 为正整数集。设函数 $f:\mathbb Z_{>0}\to\mathbb Z_{>0}$ 满足：对 $m,n\in\mathbb Z_{>0}$，等式
$$f(mn)^2=f(m^2)\,f\bigl(f(n)\bigr)\,f\bigl(m f(n)\bigr)$$
成立**当且仅当** $m$ 与 $n$ 互素。对每个正整数 $n$，求 $f(n)$ 的所有可能取值。

## 原文（English）

Let $\mathbb Z_{>0}$ denote the set of positive integers. Let $f:\mathbb Z_{>0}\to\mathbb Z_{>0}$ be a function satisfying the following property: for $m,n\in\mathbb Z_{>0}$, the equation
$$f(mn)^2=f(m^2)f(f(n))f(mf(n))$$
holds if and only if $m$ and $n$ are coprime.（Japan）

For each positive integer $n$, determine all the possible values of $f(n)$.

## 答案

与 $n$ **素因子集合相同**的全部正整数，即所有满足 $\operatorname{rad}(x)=\operatorname{rad}(n)$ 的 $x$。官方原文：*"All numbers with the same set of prime factors as n."*（官方以 $\operatorname{rad}$ 记号展开论证。）

## 解法要点

双向都要榨：「当且仅当」意味着互素时等式成立**且**不互素时必失效——后者是罕见而强力的否定性条件。教练梗概：(1) 用 $P(1,n)$、$P(n,1)$ 等边界代入建立 $f(1)$ 与 $f(f(n))$ 的基本关系；(2) 对素数 $p$，比较 $P(p,n)$ 在 $p\mid n$ 与 $p\nmid n$ 两侧的成立/失效，强制 $p\mid f(n)\iff p\mid n$（即 $\operatorname{rad}(f(n))=\operatorname{rad}(n)$——否则可造出「不互素却等式成立」或反向的违例）；(3) 构造端：证任意 $\operatorname{rad}$-保持的取值可实现——按素因子集分层定义 $f$（如在每个 rad 类内自由指定指数），逐条验证 iff 两向。难点全在 (2) 的失效方向：要会「制造违例」而非只验证恒等式。

## 提示阶梯

1. **方向**：先只用「成立」方向按套路代入特值（$m=1$、$n=1$、$m=n{-}$互素）。然后停下来问：条件的「不互素 ⇒ 失效」这一半，能用来干什么？
2. **关键结构**：目标是 $\operatorname{rad}(f(n))=\operatorname{rad}(n)$。反设某素数 $p\mid f(n)$ 但 $p\nmid n$（或反向），设法挑 $m$（含或不含 $p$）让 iff 的两个方向撞车。
3. **临门一脚**：构造：在每个「素因子集」等价类上独立定义 $f$，用类内指数的充足自由度同时满足「互素成立」与「不互素失效」；验证时按 $\operatorname{rad}$ 分解 $m,n$ 逐块检查。
