# N-018｜$k!$ 等于一般线性群的阶

## 题面

求所有正整数对 $(k,n)$，使得 $k!=(2^n-1)(2^n-2)(2^n-4)\cdots(2^n-2^{n-1})$。

## 答案

$(k,n)=(1,1)$ 与 $(3,2)$。

## 解法要点

右端的 $2$-adic 赋值恰为 $\frac{n(n-1)}{2}$，而 $v_2(k!)<k$，由此把 $k$ 与 $n$ 绑定；再用大小估计说明 $n\ge 6$ 时右端增长过快，最后手工验证 $n=3,4,5$。
