# N-015｜Doubling-Orbit Orderings Modulo N

## 题面

Let $N \ge 3$ be an integer, and $a_0, \dots, a_{N-1}$ be pairwise distinct reals so that $a_i \ge a_{2i}$ for all $i$ (indices are taken mod $N$). Find all possible $N$ for which this is possible.

## 答案

N is a power of 2

## 解法要点

The only such $N$ are powers of $2$.

If $N$ is not a power of $2$, let's say $p \nmid N$ where $p$ is an odd prime. Now, observe that $p \nmid 1$ but $p \mid 2^k - 1$ for some $k > 1$. Then, let $\alpha = \frac{N}{p}$. Now,
$$
a_{\alpha} > a_{2\alpha} \ge a_{4\alpha} \dots \ge a_{2^k \alpha} \implies a_{\alpha} > a_{2^k \alpha}
$$
But now, $a_{2^k \alpha} = a_{\alpha}$ as $N|(2^k - 1)\alpha$ but then this is a contradiction! We have that $a_{\alpha} > a_{2\alpha}$ since all reals in the circle are distinct and $N \nmid \alpha$.

Now, if $N = 2^m$ is a power of $2$, let $a_j = -\nu_2(j) + \frac{j}{2N}$. This is clearly okay if $j = N$ and if $j \ne N$ then $\nu_2(2j) = \nu_2(j) + 1$ and thus $a_j \ge a_{2j}$. $\square$

## 提示阶梯

1. 研究模 N 下不断倍增指标形成的轨道：若轨道回到起点，严格不等式会产生矛盾；能避开这种循环时则需显式构造数值。
2. 若 N 含奇素因子 p，取 α=N/p，并寻找满足 2^k≡1 (mod p) 的 k；另一方面，对只含因子 2 的情形可按指标中 2 的指数分层赋值。
3. 沿 α,2α,…,2^kα 串起不等式，并用首步严格性与末端同指标冲突。另一方向令 a_j=-ν₂(j)+j/(2N)，分别检查 j 经倍增后是否越过模 N 的边界。
