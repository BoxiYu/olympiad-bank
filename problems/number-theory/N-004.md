# N-004｜公倍数求和

## 题面

在所有是 $20$ 的倍数的自然数中，不超过 $3000$ 并且是 $14$ 的倍数的数之和是＿＿＿。

## 答案

$32340$

## 解法要点

同时是 $20$ 与 $14$ 的倍数即为 $\mathrm{lcm}(20,14)=140$ 的倍数。$140k\le 3000$ 给出 $k=1,\dots,21$，求和得 $140\cdot\frac{21\cdot 22}{2}=140\cdot 231$。
