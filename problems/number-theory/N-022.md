# N-022｜$\lfloor n^k/k\rfloor$ 中的无穷多奇数项

## 题面

设 $n>1$ 是给定的整数。证明：由 $a_k=\left\lfloor \dfrac{n^k}{k}\right\rfloor$（$k\ge 1$）定义的数列 $(a_k)_{k\ge 1}$ 中有无穷多项是奇数。

## 答案

结论成立。

## 解法要点

分 $n$ 为偶数/奇数两类构造 $k$。核心是选取形如 $k=2^t$ 或 $k=p$（合适的素数）的下标，把 $\lfloor n^k/k\rfloor$ 的奇偶性归结为 $n^k \bmod 2k$ 的计算，再用费马小定理定出该余数。
