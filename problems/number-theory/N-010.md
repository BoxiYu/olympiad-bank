# N-010｜$\sqrt{K^2-pK}$ 为正整数

## 题面

设 $p$ 为奇素数，$K$ 为正整数，使得 $\sqrt{K^2-pK}$ 也是正整数。则 $K=$ ＿＿＿。

## 答案

$K=\dfrac{(p+1)^2}{4}$（此时 $\sqrt{K^2-pK}=\dfrac{p^2-1}{4}$）

## 解法要点

设 $K^2-pK=n^2$，配方得 $(2K-p)^2-(2n)^2=p^2$，即 $(2K-p-2n)(2K-p+2n)=p^2$。由 $p$ 为素数且两因子同号，只能取 $1$ 与 $p^2$。
