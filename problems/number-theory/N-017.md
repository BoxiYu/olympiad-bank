# N-017｜与 $2^n+3^n+6^n-1$ 全体互素

## 题面

求所有与无穷数列 $a_n=2^n+3^n+6^n-1\ (n\ge 1)$ 的每一项都互素的正整数。

## 答案

只有 $1$。

## 解法要点

对素数 $p>3$，取 $n=p-2$，由费马小定理 $2^{p-2}\equiv 2^{-1}$ 等，得 $a_{p-2}\equiv \tfrac12+\tfrac13+\tfrac16-1=0 \pmod p$。$p=2,3$ 则由 $a_2=48$ 处理。
