# N-017｜Divisors Below the Square Root

## 题面

The number $n = 11^{2011} \cdot 2011^{11}$ is given. How many divisors that are less than $n$ and are not divisors of $n$, does $n^2$ have?

## 答案

22121

## 解法要点

The number of divisors of $n^2 = 11^{4022} \cdot 2011^{22}$ is:
$$
N = (4022 + 1)(22 + 1) = 92529.
$$
We can pair the divisors of $n^2$ in a way $d$ and $\frac{n^2}{d}$ where one divisor is greater than $n$, another one is less. The number $n$ does have a pair, therefore the number of divisors that are less than $n$ is $\frac{92529-1}{2} = 46264$.

The number $N_1$ of divisors of $n$ that are less than $n$ is:
$$
N_1 = (2011+1)(11+1)-1 = 24143.
$$
So the number we are looking for is $46264 - 24143 = 22121$.

## 提示阶梯

1. 先数 n² 的全部因数，再以 n 为中心配对；然后扣除其中本来就是 n 的因数者。
2. n² 的因数可配成 d 与 n²/d，除中心 n 外每对恰有一个小于 n。n 的所有因数中，仅 n 自身不小于 n。
3. 分别用指数加一法写出 τ(n²) 与 τ(n)，所求数量就是 (τ(n²)-1)/2 再减去 τ(n)-1；最后代入题给的两个指数计算。
