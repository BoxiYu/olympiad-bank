# N-002｜班级人数与男女比

## 题面

小明所在班级的人数不足 $40$ 人，但比 $30$ 人多，那么这个班男、女生人数的比不可能是（　）。$\text{(A) }2:3\quad \text{(B) }3:4\quad \text{(C) }4:5\quad \text{(D) }3:7$

## 答案

(D)

## 解法要点

若男女比为 $a:b$（既约），则总人数必是 $a+b$ 的倍数。四个选项的份数和分别为 $5,7,9,10$；在开区间 $(30,40)$ 内，$5\mid 35$、$7\mid 35$、$9\mid 36$ 均可，唯独 $10$ 的倍数不落在该区间。
