# N-040｜n-good 多项式的普适 n

## 题面

设 $n$ 为正整数。称整系数多项式 $P$ 为 **$n$-good**，若存在二次整系数多项式 $Q$，使得对任意整数 $k$，
$$Q(k)\bigl(P(k)-Q(k)\bigr)$$
都不被 $n$ 整除。求所有整数 $n$，使得**每个**整系数多项式都是 $n$-good。

## 原文（English）

Let $n$ be a positive integer. We say that a polynomial $P$ with integer coefficients is $n$-good if there exists a polynomial $Q$ of degree $2$ with integer coefficients such that $Q(k)\bigl(P(k)-Q(k)\bigr)$ is never divisible by $n$ for any integer $k$. Determine all integers $n$ such that every polynomial with integer coefficients is an $n$-good polynomial.（France）

## 答案

所有 $n>2$。官方原文：*"The set of such n is any n > 2."*

## 解法要点

小 $n$ 排除：$n=1$ 时任何数都被 $1$ 整除，无多项式是 $1$-good（官方注同此）。$n=2$：$Q(k)$ 与 $P(k)-Q(k)$ 之和为 $P(k)$——若要乘积恒奇，需两因子恒奇，即 $Q(k)$ 恒奇且 $P(k)$ 恒偶；取 $P$ 有奇值（如 $P=X$）即无合法 $Q$，故 $n=2$ 不行。$n>2$ 构造：只需对每个素数幂分量赢一次再 CRT 拼装——对奇素数 $p\mid n$，模 $p$ 的非零剩余充足，可选二次 $Q$ 使 $Q(k)\not\equiv 0$ 且 $Q(k)\not\equiv P(k)\pmod p$ 对全部剩余类成立（二次曲线可避开两张「禁止表」，因 $p\ge 3$ 每类至少剩一个可用值，再用插值/系数自由度拼出整多项式）；对 $2^t\,\|\,n$（$t\ge 2$）在模 $4$ 层面同样有回旋余地（乘积只需不被 $4$ 整除）。训练重点在「逐素数幂设计 + CRT 合成」的构造观。

## 提示阶梯

1. **方向**：先打小案子：$n=1$ 为什么全军覆没？$n=2$ 时把 $Q$ 与 $P-Q$ 的奇偶性加起来看——它们的和是谁？
2. **关键结构**：$n>2$ 时按素数幂分治：只要每个 $p^t\,\|\,n$ 上能造出「乘积模 $p^t$ 永不为 0」的 $Q_p$，CRT 把系数拼成一个 $Q$。
3. **临门一脚**：奇素数 $p$ 上，逐剩余类 $k\bmod p$ 给 $Q(k)$ 指定一个既非 $0$ 也非 $P(k)$ 的值（$p\ge 3$ 保证存在）——再问：为什么可以用**二次**多项式实现这张取值表？（自由度 + 允许把表做成常数/低自由结构。）
