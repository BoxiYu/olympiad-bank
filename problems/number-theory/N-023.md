# N-023｜勾股三元集的连通性

## 题面

称 $3$ 个正整数组成的集合 $\{a,b,c\}$ 为**勾股集**，如果 $a,b,c$ 是某个直角三角形三边的长度。证明：对任意两个勾股集 $P,Q$，存在正整数 $m\ge 2$ 及勾股集 $P_1,P_2,\dots,P_m$，使得 $P=P_1$，$Q=P_m$，且对一切 $1\le i\le m-1$ 都有 $P_i\cap P_{i+1}\ne\varnothing$。

## 答案

结论成立。

## 解法要点

把「共享一个元素」看作图的边，只需证明所有勾股集在此图中连通。关键是用 $(a,\frac{a^2-1}{2},\frac{a^2+1}{2})$ 与 $(a,\frac{a^2}{4}-1,\frac{a^2}{4}+1)$ 之类的显式族，把任意勾股集接到一条"主干链"上。
