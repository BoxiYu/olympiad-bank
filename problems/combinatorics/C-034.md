# C-034｜公鸡绕圈恰好三周

## 题面

设 $n\ge 3$ 为整数。圆周上有 $n$ 个格子，每个格子被赋值 $0$ 或 $1$。一只公鸡站在其中一个格子上，反复执行以下操作：

- 若公鸡所在格子的值为 $0$，它把该值改为 $1$，并逆时针移动到下一个格子；
- 若公鸡所在格子的值为 $1$，它把该值改为 $0$，并逆时针移动到下下个格子（跳过一格）。

求证：经过足够多次操作后，下述命题成立：若公鸡位于格子 $C$，则它将恰好绕圆周三周后再次停在 $C$，且每个格子的赋值与它绕这三周之前完全相同。

## 原文（English）

Let $n\ge 3$ be an integer. There are $n$ cells on a circle, and each cell is assigned either 0 or 1. There is a rooster on one of these cells, and it repeats the following operations:

- If the rooster is on a cell assigned 0, it changes the assigned number to 1 and moves to the next cell counterclockwise.
- If the rooster is on a cell assigned 1, it changes the assigned number to 0 and moves to the cell after the next cell counterclockwise.

Prove that the following statement holds true after sufficiently many operations: If the rooster is on a cell $C$, then the rooster would go around the circle exactly three times, stopping again at $C$. Moreover, every cell would be assigned the same number as it was assigned right before the rooster went around the circle 3 times.

## 答案

证明题；结论成立。

## 解法要点

计数恒等式定框架：一段过程中设执行 $k_0$ 次 0-操作、$k_1$ 次 1-操作，则总位移 $k_0+2k_1$，总赋值变化 $k_0-k_1$。若公鸡回到原格且盘面复原，则 $k_0=k_1$ 且位移 $3k_1$ 为 $n$ 的倍数——「恰好三周」对应 $k_0=k_1=n$。状态空间有限（盘面 $\times$ 位置）且过程确定，故轨道最终进入循环；对循环段证明每个格子在一个周期内恰被 0-操作与 1-操作各触发一次（局部交替结构排除更短或更长的周期），即得周期恰为 $3n$ 步、绕行三周。

## 核验

题面经官方解答 PDF 的重述转录。结论已程序验证：对 $n=3..8$ 的**全部** $2^n$ 种初始盘面模拟，最终循环段一律为 $2n$ 次操作、总位移 $3n$（恰三周）、0/1 操作各 $n$ 次。
