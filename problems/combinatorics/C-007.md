# C-007｜Distinct Entries in a Table

## 题面

Problem:
In a $16 \times 16$ table of integers, each row and column contains at most 4 distinct integers. What is the maximum number of distinct integers that there can be in the whole table?

## 答案

49

## 解法要点

Solution:
Answer: 49

First, we show that 50 is too big. Assume for sake of contradiction that a labeling with at least 50 distinct integers exists. By the Pigeonhole Principle, there must be at least one row, say the first row, with at least 4 distinct integers in it; in this case, that is exactly 4, since that is the maximum number of distinct integers in one row. Then, in the remaining 15 rows there must be at least 46 distinct integers (these 46 will also be distinct from the 4 in the first row). Using Pigeonhole again, there will be another row, say the second row, with 4 distinct integers in it. Call the set of integers in the first and second rows $S$. Because the 4 distinct integers in the second row are distinct from the 4 in the first row, there are 8 distinct values in the first two rows, so $|S|=8$.

Now consider the subcolumns containing the cells in rows 3 to 16. In each subcolumn, there are at most 2 values not in $S$, because there are already two distinct values in that column from the cells in the first two rows. So, the maximum number of distinct values in the table is $16 \cdot 2 + 8 = 40$, a contradiction. So a valid labeling must have fewer than 50 distinct integers.

## 提示阶梯

1. 先尝试排除“比可构造规模再多一个”的情形；行、列各自至多容纳四种值，适合连续两次使用抽屉原理。
2. 在假设总数过多时，可先后找到两行，每行都贡献四个彼此不同的新值。于是每一列的前两格已经占去两个不同值，余下各格至多再出现两个不属于这两行值集的值。
3. 对下界构造，在方阵中沿三个循环错位的对角线分别放置互不相同的值，其余格统一填同一个新值。逐行、逐列检查，都会恰好只见到这三类对角线值与公共填充值。
