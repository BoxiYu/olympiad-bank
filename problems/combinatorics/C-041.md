# C-041｜Cantor Set Expected Distance

## 题面

Problem:
The Cantor set is defined as the set of real numbers $x$ such that $0 \leq x < 1$ and the digit $1$ does not appear in the base-$3$ expansion of $x$. Two numbers are uniformly and independently selected at random from the Cantor set. Compute the expected value of their absolute difference.

(Formally, one can pick a number $x$ uniformly at random from the Cantor set by first picking a real number $y$ uniformly at random from the interval $[0,1)$, writing it out in binary, reading its digits as if they were in base-$3$, and setting $x$ to $2$ times the result.)

## 答案

2/5

## 解法要点

Solution:
Let $d$ be the expected value of the absolute difference. Observe that the Cantor set is made up of two smaller copies of itself, each scaled down by a factor of $3$. There is a $\frac{1}{2}$ chance that the two selected numbers are in the same copy, in which case the expected value of their absolute difference is $\frac{1}{3} d$. Otherwise, we can write them as $\frac{2 + x}{3}$ and $\frac{y}{3}$ for independently and uniformly randomly selected $x$ and $y$ in the Cantor set. Their difference is $\frac{2 + (x - y)}{3}$, which by symmetry has expected value $\frac{2}{3}$. Thus
$$
d = \frac{1}{2}\cdot \frac{1}{3} d + \frac{1}{2}\cdot \frac{2}{3} \Rightarrow d = \left[\frac{2}{5}\right].
$$

## 提示阶梯

1. 从 Cantor 集的自相似性入手，按两点落在同一小副本还是不同小副本分类讨论距离。
2. 设原集合中两点距离的期望为 d；同一副本内的距离按比例缩小，不同副本间则利用两个随机点的对称性处理偏移量。
3. 同副本情形贡献 d/3，异副本情形的期望距离为 2/3，因此列出 d=½·(d/3)+½·(2/3)，再解这个方程。
