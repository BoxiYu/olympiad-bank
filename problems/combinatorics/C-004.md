# C-004｜九个整数中的平方差

## 题面

证明：任意 $9$ 个整数中，至少有两个整数的平方差是 $8$ 的倍数。

## 答案

证明题；结论成立。

## 解法要点

整数按模 $8$ 的余数只需分为 $0,\pm1,\pm2,\pm3,4$ 这几类的"平方同类"，实质上 $n^2 \bmod 8$ 只取 $0,1,4$，或按余数绝对值分四类。由抽屉原理，$9$ 个数中必有两个同类，其平方差被 $8$ 整除。
