# C-030｜Two-Coloring Without Infinite Progressions

## 题面

Is it possible to partition the set of the positive integers into two subsets such that none of them contains an infinitely long (non-constant) arithmetic progression?

## 答案

Yes

## 解法要点

The answer is in the affirmative. For example, one can consider
$$A = \{1, 3, 4, 7, 8, 9, 13, 14, 15, 16, 21, \dots\},$$
$$B = \{2, 5, 6, 10, 11, 12, 17, 18, 19, 20, 26, \dots\},$$
i.e., for the infinite word $W = w_1w_2\cdots w_k \cdots = aba^2b^2\cdots a^nb^n\cdots$, put $A$ the set of the indices $i$ for which $w_i = a$, and $B$ the set of the indices $i$ for which $w_i = b$. The terms of an arithmetic progression are equally spaced, while $A$ and $B$ both contain arbitrarily long gaps, hence the conclusion follows readily.

## 提示阶梯

1. 尝试构造两种颜色交替出现的块，并让每种颜色都出现任意长的空档。
2. 让同色块长度逐次增加，按 $a,b,a^2,b^2,\ldots,a^r,b^r,\ldots$ 拼成无限词，再按位置所属字母分组。
3. 若某一组含有公差固定的无限等差数列，那么相邻两项间距恒定；但该组的补色块长度无界，终会形成比该公差更长的空档，从而截断这条数列。
