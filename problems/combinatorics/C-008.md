# C-008｜两条平行线上的三角形

## 题面

直线 $a$ 平行于直线 $b$，$a$ 上有 $11$ 个点，$b$ 上有 $10$ 个点，用线段连接各点。所得图形中，有一条边在 $a$ 上或 $b$ 上的三角形有多少个？

## 答案

$5995$

## 解法要点

分两类。三个顶点都在两条平行线上：$\binom{11}{2}\cdot 10+\binom{10}{2}\cdot 11=550+495=1045$；两个顶点在同一条平行线上、第三个顶点是两条连线的交点：$4950$。合计 $5995$。
