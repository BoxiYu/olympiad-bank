# C-001｜兔子跳台阶

## 题面

小兔 Buzz 在一段台阶上上下跳，每次跳一级。它从地面出发，跳 $6$ 次后又回到地面，问共有多少种不同的跳法？

## 答案

$5$（选项 B）

## 解法要点

把"上"记作 $U$、"下"记作 $D$，则合法序列即长度 $6$ 的 Dyck 路径；任何前缀中 $D$ 的个数不得超过 $U$。直接枚举或用 Catalan 数 $C_3=5$。
