# C-027｜猎人与隐形的兔子

## 题面

一名猎人与一只隐形的兔子在欧氏平面上做游戏。兔子的起点 $A_0$ 与猎人的起点 $B_0$ 相同。经过 $n-1$ 轮后，兔子位于点 $A_{n-1}$，猎人位于点 $B_{n-1}$。在第 $n$ 轮中依次发生三件事：(i) 兔子隐形地移动到点 $A_n$，使得 $A_{n-1}$ 与 $A_n$ 的距离恰为 $1$；(ii) 一个追踪装置向猎人报告一个点 $P_n$，该装置唯一的保证是 $P_n$ 与 $A_n$ 的距离至多为 $1$；(iii) 猎人公开地移动到点 $B_n$，使得 $B_{n-1}$ 与 $B_n$ 的距离恰为 $1$。问：无论兔子如何移动、无论追踪装置报告哪些点，猎人是否总能选择自己的移动方式，保证经过 $10^9$ 轮后她与兔子的距离至多为 $100$？

## 答案

**否**（不能保证）。

## 解法要点

给出兔子（与装置合谋）的策略：兔子在两条对称的候选轨迹之间保持"歧义"，每一段中把与猎人的距离从 $d$ 抬高到约 $\sqrt{d^2+1}$，而报告点始终与两条候选轨迹都相容。经过约 $d^2$ 段即可把距离推进 $1$，总轮数 $10^9$ 足以把距离推到 $100$ 以上。
