# C-013｜2×6 方格中的模 3 约束

## 题面

设 $N$ 为把整数 $1$ 到 $12$ 填入 $2\times 6$ 方格表的 $12$ 个格子中的填法数，使得任意两个共边的格子中所填的两数之差都不被 $3$ 整除。求 $N$ 的正因数个数。

## 答案

$144$

## 解法要点

先对格子按模 $3$ 余数"染色"，条件等价于相邻格余数不同，而 $0,1,2$ 三类各恰有 $4$ 个数。先数合法的余数图案，再乘以每类内部 $4!$ 的分配；最终 $N=2^{11}\cdot 3^5\cdot 5$，因数个数 $12\cdot6\cdot2=144$。
