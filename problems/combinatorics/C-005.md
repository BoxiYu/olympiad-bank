# C-005｜掷骰子的 running total

## 题面

Janet 掷一枚标准的六面骰子 $4$ 次，并记录累计和。问在某一时刻她的累计和恰好等于 $3$ 的概率是多少？

## 答案

$\dfrac{49}{216}$（选项 B）

## 解法要点

累计和触及 $3$ 只可能通过三条互斥路径：首掷为 $3$；前两掷为 $(1,2)$ 或 $(2,1)$；前三掷为 $(1,1,1)$。概率相加 $\frac16+\frac1{18}+\frac1{216}=\frac{49}{216}$。
