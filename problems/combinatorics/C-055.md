# C-055｜Cyclic Four-Term Balance

## 题面

$n \ge 4$ real numbers are placed on the circle. It is known that for any four consecutive numbers $a, b, c, d$ that go around the circle in this specified order, the condition $a + d = b + c$ holds. For which $n$ can we conclude that all the numbers are equal?

## 答案

all odd n

## 解法要点

We denote the numbers in the circle by $a_1, a_2, \ldots, a_n$. Choose the largest among them (or any of them, if there are several such numbers). Without loss of generality, let this number be $a_1$. From the condition of the problem we have that
$$
a_1 + a_2 = a_n + a_3, \quad a_1 + a_n = a_2 + a_{n-1} \Rightarrow 2a_1 = a_3 + a_{n-1}.
$$
Since $a_1$ is the largest number, the last equality implies that $a_1 = a_3 = a_{n-1}$: that is, every second number is the largest, if we continue with the same reasoning. If $n$ is odd, then all the numbers will be equal.

For even numbers $n$ it is enough to consider the following example with not all equal numbers: $1, 0, 1, 0, \ldots, 1, 0$.

## 提示阶梯

1. 从圆上一个最大项出发，观察题设等式能否把“取到最大值”沿固定步长传播。
2. 设最大项为 $a_1$，联立它两侧的两个四项关系可得 $2a_1=a_3+a_{n-1}$；由极大性，两项都只能等于 $a_1$。
3. 继续重复同一论证，最大值会沿下标每次跨两格传播；检查这种步长绕圆一周覆盖哪些位置。对未覆盖全部位置的情形，再用两个数交替排列检验题设。
