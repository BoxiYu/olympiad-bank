# A-006｜完全可加函数

## 题面

设 $f$ 是定义在正有理数集上的函数，满足对任意正有理数 $a,b$ 有 $f(a\cdot b)=f(a)+f(b)$，且对每个素数 $p$ 有 $f(p)=p$。下列哪个数 $x$ 使得 $f(x)<0$？
$\textbf{(A) } \frac{17}{32}\quad \textbf{(B) } \frac{11}{16}\quad \textbf{(C) } \frac79\quad \textbf{(D) } \frac76\quad \textbf{(E) } \frac{25}{11}$

## 答案

$\textbf{(E) } \frac{25}{11}$（$f\!\left(\tfrac{25}{11}\right)=-1$）

## 解法要点

由可加性推出 $f\!\left(\tfrac mn\right)=f(m)-f(n)$，且 $f\!\left(\prod p_i^{e_i}\right)=\sum e_ip_i$。于是把每个选项按素因数分解逐一算"权重和"之差即可。
