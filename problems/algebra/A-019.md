# A-019｜Cyclic Cubic System

## 题面

Solve the system of equations over real numbers:
$$
\begin{cases}
x^3 = 2y^3 + z - 2, \\
y^3 = 2z^3 + x - 2, \\
z^3 = 2x^3 + y - 2.
\end{cases}
$$

## 答案

(1, 1, 1)

## 解法要点

From the first two equations of our system we obtain: $x^3 - y^3 = 2y^3 - 2z^3 + y - z = (y-z)(2y^2 + 2yz + 2z^2 + 1)$, analogously, we can easily get equalities: $y^3 - z^3 = (z-x)(2z^2 + 2zx + 2x^2 + 1)$, $z^3 - x^3 = (x-y)(2x^2 + 2xy + 2y^2 + 1)$. It is easy to see that $(2y^2 + 2yz + 2z^2 + 1) = y^2 + z^2 + (y+z)^2 + 1 > 0$. If we suppose that $y > z$, then from the first equality we have that $x > y$, then applying third equality we conclude: $z > x > y > z$ - contradiction. The case when $y < z$ is completely analogous. Hence we obtain $x = y = z$. and solving the equation we get the answer $(1,1,1)$.

## 提示阶梯

1. 研究相邻变量的大小关系能否沿三个方程循环传播，不必直接求解各个三次式。
2. 相减后可把立方差与另一个变量差联系起来，且乘在变量差旁的二次式恒为正，因此能确定差的符号。
3. 例如由前两式得 $x^3-y^3=(y-z)(2y^2+2yz+2z^2+1)$。假设 $y>z$，沿另外两条同类等式追踪会形成循环严格大小矛盾；反向情形同理，随后令三变量相等代回。
