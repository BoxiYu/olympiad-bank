# A-003｜Cubic–Quartic Equality Triple

## 题面

a. Show that $x^4 - x^3 - x + 1 \ge 0$, for all real numbers $x$.

b. Find all real numbers $x_1, x_2$ and $x_3$ given that $x_1 + x_2 + x_3 = 3$ and $x_1^3 + x_2^3 + x_3^3 = x_1^4 + x_2^4 + x_3^4$.

## 答案

x1 = x2 = x3 = 1

## 解法要点

a. Write $x^4 - x^3 - x + 1 = (x-1)(x^3 - 1) = (x-1)^2(x^2 + x + 1)$ and notice that $x^2 + x + 1 > 0$ for all $x \in \mathbb{R}$ to get the claim.

b. Notice that $\sum_{k=1}^{3} (x_k^4 - x_k^3 - x_k + 1) = 0$ and use (a) to derive that $x_1^4 - x_1^3 - x_1 + 1 = 0$, $k = 1, 2, 3$. It follows that $x_1 = x_2 = x_3 = 1$.
