# A-003｜四数两两平均

## 题面

一行写着四个数。前两个数的平均数是 $21$，中间两个数的平均数是 $26$，最后两个数的平均数是 $30$。那么第一个数与最后一个数的平均数是多少？
$\textbf{(A) } 24\quad \textbf{(B) } 25\quad \textbf{(C) } 26\quad \textbf{(D) } 27\quad \textbf{(E) } 28$

## 答案

$\textbf{(B) } 25$

## 解法要点

记四数为 $a,b,c,d$，则 $a+b=42,\ b+c=52,\ c+d=60$。作交错求和 $(a+b)-(b+c)+(c+d)=a+d=50$，无需解出各数。
