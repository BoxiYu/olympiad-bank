# A-043｜Shifted Sum-of-Squares Equation

## 题面

Problem:

Find the real solution(s) to the equation $(x+y)^2 = (x+1)(y-1)$.

## 答案

(-1, 1)

## 解法要点

Solution:

Answer: $(-1,1)$

Set $p = x + 1$ and $q = y - 1$, then we get $(p + q)^2 = p q$, which simplifies to $p^2 + p q + q^2 = 0$. Then we have $\left(p + \frac{q}{2}\right)^2 + \frac{3 q^2}{4} = 0$, and so $p = q = 0$. Thus $(x, y) = (-1, 1)$.

## 提示阶梯

1. 平移变量，使等式右边的两个一次因子直接成为新变量，并观察左边的和如何随之变化。
2. 令 $p=x+1,\ q=y-1$，原式化为 $(p+q)^2=pq$，即 $p^2+pq+q^2=0$。
3. 把左端配成 $\left(p+\frac q2\right)^2+\frac34q^2$；两个非负项之和为零会迫使它们同时为零，再回代平移关系。
