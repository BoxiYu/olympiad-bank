# A-004｜填空里的正整数个数

## 题面

有多少个正整数可以填入下面这句话的空格中？"一个正整数比另一个正整数的 $2$ 倍多 ______，且这两个数之和是 $28$。"
$\textbf{(A) } 6\quad \textbf{(B) } 7\quad \textbf{(C) } 8\quad \textbf{(D) } 9\quad \textbf{(E) } 10$

## 答案

$\textbf{(D) } 9$

## 解法要点

设较小数为 $n$，较大数为 $28-n$，空格中的数 $d=(28-n)-2n=28-3n$。要求 $n\ge 1$ 且 $d\ge 1$（均为正整数），得 $n=1,2,\dots,9$。
