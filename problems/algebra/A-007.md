# A-007｜两个对数求和之积

## 题面

求 $\left(\sum_{k=1}^{20}\log_{5^k}3^{k^2}\right)\cdot\left(\sum_{k=1}^{100}\log_{9^k}25^k\right)$ 的值。
$\textbf{(A) } 21\quad \textbf{(B) } 100\log_5 3\quad \textbf{(C) } 200\log_3 5\quad \textbf{(D) } 2200\quad \textbf{(E) } 21000$

## 答案

$\textbf{(E) } 21000$

## 解法要点

$\log_{5^k}3^{k^2}=k\log_5 3$，第一个和为 $210\log_5 3$；$\log_{9^k}25^k=\log_9 25=\log_3 5$，第二个和为 $100\log_3 5$。两者相乘时 $\log_5 3\cdot\log_3 5=1$ 抵消。
