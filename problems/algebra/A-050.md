# A-050｜Coincident Rational Power Sums

## 题面

Let $S_r(n) = 1^r + 2^r + \dots + n^r$ where $r$ is a rational number and $n$ is a positive integer. Find all triples $(a, b, c)$ where $a$ and $b$ are positive rational numbers and $c$ is a positive integer for which there exist infinitely many positive integers $n$ satisfying $S_a(n) = (S_b(n))^c$.

## 答案

All triples are: (a, b, c) = (3, 1, 2) and the family with c = 1 and a = b any positive rational.

## 解法要点

The answer is $a = 3, b = 1, c = 2$ and $a = b \in \mathbb{Q}^+, c = 1$.
Applying induction on $n$ by using Bernoulli's inequality gives
$$
\frac{n^{r+1}}{r+1} \le S_r(n) \le \frac{(n+1)^{r+1}}{r+1}
$$
for all positive integer $n$ and positive rational number $r$.
As $S_a(n) = (S_b(n))^c$ letting $r = a$ and $r = b$ gives that
$$
\frac{n^{a+1}}{a+1} \le \left( \frac{(n+1)^{b+1}}{b+1} \right)^c \text{ and } \left( \frac{n^{b+1}}{b+1} \right)^c \le \frac{(n+1)^{a+1}}{a+1}
$$
i.e.
$$
\frac{n^{(b+1)c}}{(n+1)^{a+1}} \le \frac{(b+1)^c}{a+1} \le \frac{(n+1)^{(b+1)c}}{n^{a+1}}
$$
holds for infinitely many positive integers $n$. By letting $n \to \infty$ in the last inequality, we obtain that $(b+1)c = a+1$ and $(b+1)^c = a+1$. If $c=1$, then $a=b$ and we get the trivial solutions.
If $c > 1$, then $c = (b+1)^{c-1}$ implies that $b$ is an integer since $c$ is an integer. As $b \ge 1$, we get that $c \ge 2^{c-1}$ and hence $c = 2$. This leads to $b = 1, a = 3$ and this solution clearly satisfies the condition.

## 提示阶梯

1. 先用幂和的上下界比较两边随 n 增长的阶，而不要尝试逐项相等。无限多个 n 允许沿这些 n 取极限。
2. 使用 n^(r+1)/(r+1)≤S_r(n)≤(n+1)^(r+1)/(r+1) 同时夹住等式两边。极限会分别迫使增长指数与首项系数满足 (b+1)c=a+1 和 (b+1)^c=a+1。
3. 消去 a 后得到只含 b、c 的方程；分别处理指数取乘法单位元与大于单位元的情形。后一情形先说明 b 必为整数，再由 b≥1 导出的指数不等式把可能性压到极少，逐一检验即可。
