# A-005｜两个底数的对数方程

## 题面

方程 $\log_{3x} 4=\log_{2x} 8$ 的解（其中 $x$ 是正实数且 $x\neq \frac13,\ x\neq\frac12$）可写成 $\frac pq$，其中 $p,q$ 是互质的正整数。求 $p+q$。
$\textbf{(A) } 5\quad \textbf{(B) } 13\quad \textbf{(C) } 17\quad \textbf{(D) } 31\quad \textbf{(E) } 35$

## 答案

$\textbf{(D) } 31$（即 $x=\tfrac{4}{27}$）

## 解法要点

设公共值为 $t$，则 $(3x)^t=4=2^2$、$(2x)^t=8=2^3$。两式指数比为 $2:3$，故 $(3x)^3=(2x)^2$，得 $27x^3=4x^2$。
