# A-008｜Polynomial-Line Intersections

## 题面

Problem:

Dan je polinom $p$ s predpisom $p(x)=x^{4}+3 x^{3}+a x^{2}+b x+7$. Določi števili $a$ in $b$ tako, da bo premica $z$ enačbo $y=2 x+7$ sekala graf polinoma $p$ v točkah $z$ abscisama 1 in -4.

## 答案

a = -4, b = 2

## 解法要点

Solution:

Zapišemo enačbo $2 x+7 = x^{4} + 3 x^{3} + a x^{2} + b x + 7$. Enačbo uredimo in dobimo $x^{4} + 3 x^{3} + a x^{2} + (b-2) x = 0$.

V enačbo vstavimo $x=1$ in dobimo $1 + 3 + a + b - 2 = 0$ oziroma $a + b + 2 = 0$.

V enačbo vstavimo še $x = -4$ in dobimo $256 - 192 + 16 a - 4 b + 8 = 0$ oziroma $4 a - b + 18 = 0$.

Rešimo sistem enačb:

$a + b + 2 = 0$

$4 a - b + 18 = 0$

Seštejemo obe enačbi:

$a + b + 2 = 0 \implies b = -a - 2$

Vstavimo v drugo enačbo:

$4a - (-a - 2) + 18 = 0$

$4a + a + 2 + 18 = 0$

$5a + 20 = 0$

$a = -4$

$b = -(-4) - 2 = 4 - 2 = 2$

Torej sta $a = -4$ in $b = 2$.


Drugi način:

Izračunamo koordinate presečišč premice in grafa polinoma $(1,9)$ in $(-4,-1)$. Koordinate obeh točk vstavimo v predpis za polinom. Dobimo enačbi:

Za $x=1$: $p(1) = 1 + 3 + a + b + 7 = 11 + a + b = 9 \implies a + b = -2$

Za $x=-4$: $p(-4) = 256 - 192 + 16a - 4b + 7 = 71 + 16a - 4b = -1 \implies 16a - 4b = -72 \implies 4a - b = -18$

Rešimo sistem:

$a + b = -2$

$4a - b = -18$

Seštejemo obe enačbi:

$a + b = -2 \implies b = -2 - a$

$4a - (-2 - a) = -18$

$4a + a + 2 = -18$

$5a = -20$

$a = -4$

$b = -2 - (-4) = 2$

Torej sta $a = -4$ in $b = 2$.

## 提示阶梯

1. 把给定横坐标确实是交点这一条件，翻译成直线与多项式在这两个输入处取值相同。
2. 令 $p(x)-(2x+7)=0$，两个指定横坐标分别代入后，会得到关于 $a,b$ 的两个一次方程。
3. 整理得 $x^4+3x^3+ax^2+(b-2)x=0$；将题给的两个横坐标代入，随后消元解这个二元一次方程组。
