# A-011｜Nested Trigonometric Equation

## 题面

Does the equation $\cos(\sin x) = \sin(\cos x)$ have at least one real solution?

## 答案

No

## 解法要点

Rewrite the equation as $\cos(\sin x) = \cos\left(\frac{\pi}{2} - \cos x\right)$. This implies that $\frac{\pi}{2} - \cos x = \pm \sin x + 2k\pi$ for some $k \in \mathbb{Z}$, so $\cos x \pm \sin x = \frac{\pi}{2} - 2k\pi$. Since $|\cos x \pm \sin x| \le |\cos x| + |\sin x| \le 2$, we have $k=0$, and so $\cos x \pm \sin x = \frac{\pi}{2}$. Squaring both sides of the equation we get $\cos^2 x \pm 2\cos x\sin x + \sin^2 x = \frac{\pi^2}{4}$ or $\pm \sin 2x = \frac{\pi^2}{4} - 1$. Since $\frac{\pi^2}{4} - 1 > \frac{9}{4} - 1 > 1$, this equation has no real solutions, so the initial equation does not have any real solutions either.

## 提示阶梯

1. 设法把等式两边改写成同一种三角函数，再比较其所有可能的角度关系。
2. 将右边写成 $\cos(\pi/2-\cos x)$，于是两个角相差符号与整周期；再用 $\cos x\pm\sin x$ 的取值范围限制周期参数。
3. 角度关系化为 $\cos x\pm\sin x=\pi/2-2k\pi$ 后先确定 $k$，再平方并用 $\sin 2x$ 的取值范围检验所得等式能否成立。
