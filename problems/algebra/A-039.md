# A-039｜Shifted Radical Equation

## 题面

Solve the equation:
$$
\frac{1}{\sqrt{2014}-\sqrt{x}} + \frac{1}{\sqrt{2015}-\sqrt{x+1}} + \frac{1}{\sqrt{2016}-\sqrt{x+2}} = 
\frac{1}{\sqrt{2015-x}-\sqrt{1}} + \frac{1}{\sqrt{2016-x}-\sqrt{2}} + \frac{1}{\sqrt{2017-x}-\sqrt{3}}
$$

## 答案

1

## 解法要点

Multiply both numerator and denominator by the conjugate:
$$
\frac{\sqrt{2014+\sqrt{x}}}{2014-x} + \frac{\sqrt{2015+\sqrt{x+1}}}{2015-(x+1)} + \frac{\sqrt{2016+\sqrt{x+2}}}{2016-(x+2)} = \frac{\sqrt{2015-x+\sqrt{1}}}{(2015-x)-1} + \frac{\sqrt{2016-x+\sqrt{2}}}{(2016-x)-2} + \frac{\sqrt{2017-x+\sqrt{3}}}{(2017-x)-3}
$$
After multiplying by the common denominator we have:
$$
\sqrt{2014+\sqrt{x}} + \sqrt{2015+\sqrt{x+1}} + \sqrt{2016+\sqrt{x+2}} = 
\sqrt{2015-x} + \sqrt{1} + \sqrt{2016-x} + \sqrt{2} + \sqrt{2017-x} + \sqrt{3},
$$

1) $x=1$ is the solution of the equation:
$$
\sqrt{2014} + \sqrt{1} + \sqrt{2015} + \sqrt{2} + \sqrt{2016} + \sqrt{3} = \sqrt{2014} + \sqrt{1} + \sqrt{2015} + \sqrt{2} + \sqrt{2016} + \sqrt{3}.
$$

2) Denote $S = \sqrt{2014} + \sqrt{1} + \sqrt{2015} + \sqrt{2} + \sqrt{2016} + \sqrt{3}$. For $x > 1$ we have
$$
\sqrt{2014} + \sqrt{x} + \sqrt{2015} + \sqrt{x+1} + \sqrt{2016} + \sqrt{x+2} > 
\sqrt{2014} + \sqrt{1} + \sqrt{2015} + \sqrt{2} + \sqrt{2016} + \sqrt{3} = S.
$$
So the left-hand side is greater than $S$, and in the same way we analyze the right-hand side:
$$
\sqrt{2015-x} + \sqrt{1} + \sqrt{2016-x} + \sqrt{2} + \sqrt{2017-x} + \sqrt{3} < 
\sqrt{2014} + \sqrt{1} + \sqrt{2015} + \sqrt{2} + \sqrt{2016} + \sqrt{3} = S.
$$
So in this interval there are no roots. The same holds for $x < 1$.

## 提示阶梯

1. 尝试把每个根式差的倒数有理化，观察各项分母是否其实相同。
2. 乘以共轭式后，等式两边的每一项都有同一个分母；约去它后，只需比较两组根式和随 $x$ 的变化。
3. 找出使左侧变量根式与右侧对应根式逐项配对相等的分界点；偏离该点向一侧时左和增而右和减，向另一侧时不等号反向，从而排除其余情形。
