# A-033｜Finite Möbius Iteration

## 题面

Given that $f(x) = \frac{ax+b}{cx+d}$, $f(0) \neq 0$, $f(f(0)) \neq 0$. Let $F(x) = \underbrace{f(\dots(f(x)\dots))}_{n \text{ times}}$. If $F(0) = 0$, show that $F(x) = x$ for all $x$ where the expression is defined.

## 答案

证明题

## 解法要点

Put $f^k(x) = \underbrace{f(\dots(f(x))\dots)}_{k \text{ times}}$. Then we have $f^k(x) = \frac{a_k x + b_k}{c_k x + d_k}$. From
$f^{k+1}(x) = f(f^k(x))$ we get:
$$
\begin{align*} 
a_{k+1} &= a a_k + b c_k \
b_{k+1} &= a b_k + b d_k \
c_{k+1} &= c a_k + d c_k \
d_{k+1} &= c b_k + d d_k 
\end{align*}
$$
But we also have $f^{k+1}(x) = f^k(f(x))$, so
$$
\begin{align*} 
a_{k+1} &= a a_k + c b_k \
b_{k+1} &= b a_k + d b_k \
c_{k+1} &= a c_k + c d_k \
d_{k+1} &= b c_k + d d_k 
\end{align*}
$$
Comparing, we get $b c_k = c b_k$ and $(a-d) b_k = b(a_k - d_k)$.
If $f^n(0) = 0$, then $b_n = 0$, so $b c_n = 0$. We are given that $f(0) \neq 0$, so $b \neq 0$. Hence $c_n = 0$. Also $b(a_n - d_n) = 0$ and hence $a_n = d_n$. Hence $f^n(x) = x$.

## 提示阶梯

1. 不要直接展开复合式；跟踪每次迭代后分式线性变换的四个系数。
2. 把 $f^k(x)$ 写成 $\frac{a_kx+b_k}{c_kx+d_k}$，分别从 $f\circ f^k$ 与 $f^k\circ f$ 计算下一次迭代，并比较对应系数。
3. 由 $F(0)=0$ 先得到 $b_n=0$；再结合 $f(0)\ne0$ 推出 $b\ne0$，代入系数比较式依次确定 $c_n$ 以及 $a_n-d_n$。
