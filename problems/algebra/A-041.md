# A-041｜Deleted-Digit Difference

## 题面

Andriy wrote a 4-digit number. Olesya crossed out the last digit and it turned out that the difference between the initial number and the obtained number equals $2018$. Which number did Andriy write? Provide all possible answers.

## 答案

2242

## 解法要点

Let $abcd$ denote the number Andriy wrote, then $\overline{abcd} - \overline{abc} = 2018$. Now we only need to pick corresponding digits. Obviously, $a = 2$ or $a = 3$.

With $a = 3$, $\overline{3bcd} - \overline{3bc} > 3000 - 399 > 2018$, hence, $a = 2$ and $\overline{2bcd} - \overline{2bc} = 2018$. Analogously, $b = 2$ or $b = 3$.

With $b = 3$, $\overline{33cd} - \overline{33c} > 3300 - 339 > 2018$, therefore, $b = 2$ and $\overline{22cd} - \overline{22c} = 2018$. Analogously, $c = 3$ or $c = 4$.

When $c = 4$, we get $\overline{224d} - \overline{224} > 2240 - 224 = 2016$, therefore, the first solution would be in the form: $2242 - 224 = 2018$.

When $c = 3$, we get $\overline{223d} - \overline{223} < 2239 - 223 = 2016$, which means previously found solution is unique possible.

## 提示阶梯

1. 把四位数记作 $\overline{abcd}$，删去末位后的数就是 $\overline{abc}$；利用各位数字的取值范围逐位缩小可能性。
2. 先用四位数与三位数的上下界排除较大的千位候选，再对百位重复同样比较，最后十位只会留下相邻的两个候选。
3. 对这两个十位候选，分别让末位数字在允许范围内取到最大或最小，比较所得差与题给差值；排除一支后，直接由差式求末位。
