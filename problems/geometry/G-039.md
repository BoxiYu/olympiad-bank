# G-039｜Parallelogram Intersecting Circumcircles

## 题面

Let $ABCD$ be a parallelogram and let $M$ be the intersection of its diagonals. The circumcircle of $\triangle ABM$ intersects the line segment $AD$ in $E \ne A$ and the circumcircle of $\triangle EMD$ intersects the line segment $BE$ in the point $F \ne E$.
Prove that $\angle ACB = \angle DCF$.

## 答案

证明题

## 解法要点

We first show that $CBFD$ is a cyclic quadrilateral. Note that
$$
\angle BCD = \angle BAD \quad \text{(parallelogram)}
= \angle BAE = 180^\circ - \angle EMB \quad \text{(EABM is cyclic)}
= \angle EMD = \angle EFD \quad \text{(inscribed angle theorem in EFMD)}
= 180^\circ - \angle BFD
$$
Therefore $CBFD$ is a cyclic quadrilateral. Using the inscribed angle theorem with respect to cyclic quadrilaterals $EABM$, $EFMD$, and $CBFD$ when necessary, we see that
$$
\angle ACD = \angle CAB = \angle MAB = \angle MEB = \angle MEF \\
= \angle MDF = \angle BDF = \angle BCF.
$$
So $\angle ACF + \angle FCD = \angle ACD = \angle BCF = \angle BCA + \angle ACF$. If we subtract $\angle ACF$ from this we find that $\angle ACB = \angle DCF$, as required. $\square$

## 提示阶梯

1. 先把两个已知圆与平行四边形的角关系串起来，尝试补出一个包含 $B,C,D,F$ 的圆。
2. 沿着 $\angle BCD=\angle BAD=\angle BAE$，再借 $A,B,M,E$ 和 $E,M,D,F$ 共圆，把它连接到 $\angle BFD$，即可判定 $B,C,D,F$ 共圆。
3. 在三个圆中连续搬运角：把 $\angle ACD$ 依次化为 $\angle MAB,\angle MEB,\angle MEF,\angle MDF,\angle BDF,\angle BCF$。再在点 $C$ 处分拆这两个大角并约去公共的 $\angle ACF$。
