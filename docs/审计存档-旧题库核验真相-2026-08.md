# 审计存档：旧题库（164 题）核验声明的独立审计

> 归档性质：历史结论。审计对象是 legacy-bank-v1.9 的 164 道题（已决定整体丢弃、换 MathNet 供给）。
> 起因：馆主质疑「官方源逐字比对」这一说法的依据。审计确认：该说法此前仅来自仓库自报
> （frontmatter verification 字段 + 提交信息），未经独立核验。本文是四通道独立实证的结果。
> 审计执行：2026-08-04，四个并行审计 agent，全程只读，所有比对亲手执行、不采信任何自报。

## 总裁决

**自报的「官方逐字」在可验证样本中约 85–90% 成立；答案层未发现任何造假；
但 83% 的 sourced 题在文件内没有证据链，且抓出 2 道实质错误题与一批「伪逐字」声明。**
馆主的质疑成立：自报核验记录不能全信，必须独立抽查。

## 四通道结果

### A｜本地官方 PDF 逐字比对（28 题，ISL 2024 全量）
- 逐字一致 18；轻微差异 8（掉首句/掉括注的系统性漏抄模式）；**实质不符 2**：
  - **A-039**（ISL 2024 A3）：不等号方向与官方相反（官方 `< 1/2024`，库内 `≥`），
    导致题面与自己抄录的官方答案「是」在数学上矛盾——旧库最严重的一题。
  - **A-040**（ISL 2024 A4）：官方为差式 `f(a+b)−f(a)−f(b)`，库内被写成商式变体——
    抽取层丢负号后被 AI「按语义复原」凭空造出分式。
- 共同模式：出错题的 verification_note 自己留有口供（「符号在抽取层缺失，按官方解答语义定为…」）——
  所谓「逐字比对」在这些题上实际是**丢符号文本 + AI 猜测重构**。

### B｜MathNet 独立转录交叉验证（33 题可比）
- 逐字一致 18、轻微 8、非逐字 4（含 A 通道 2 题 + A-043 `p<q`vs`p≠q`、N-040 正负号，后两处数学等价但 note 自称「逐字」不实）、MathNet 未收录 3。
- **关键副产品：所有可仲裁分歧点上，MathNet 与官方 PDF 全部一致，出错一方全部是本库**
  （MathNet 侧仅 Saudi Booklet 三行有标点级小错）。这构成对「题库全换 MathNet」决策的强支持证据。

### C｜source_url 网络抽查（10 题分层抽样）
- 逐字一致 8、轻微 2、实质不符 0；全库 115 个唯一 URL 无一死链（AoPS 403 为反爬）。
- 两处 URL 记载笔误（C-031、G-024 缺 .pdf 扩展名）。

### D｜程序验证重跑 + 独立推导审计（15 项）
- 四个 verify 脚本重跑全部 exit 0；6 道 independent-derivation 题用**不同路线**独立复算全部一致；
  3 道盲验（只读题面写脚本）全部命中声称答案。**答案层零造假。**
- 但凭证质量有洞：isl2024_verify.py 的 C5 段有运算符优先级 bug（输出恒空的废码，幸未被引用为凭证）；
  C3 段声称覆盖 n=4 实际只算到 n=3（声明为真但凭证不覆盖）；**C-009 与 G-011 是同一道题重复入库两个板块**。

## 证据链结构性结论

- 158 道 sourced 题中仅 27 道有 verification_note，**131 道（83%）是裸声明**——
  「sourced」字段本身不构成证据。
- 凡 note 出现「按语义定为/复原」字样 = 未完成逐字核验，应降级处理。
- 新题库的入库规范应吸取的教训：**核验凭证必须落盘可复查**（评审 verdicts.json 归档 +
  「数据集声称 ≠ 已核验」条款），裸声明字段不再被信任。
