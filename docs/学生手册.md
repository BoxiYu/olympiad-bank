# 学生手册

给学生的一页流程（当前第一个学生：馆主本人）。教练侧的设计原理见 `docs/教练手册.md`。

## 1. 一次训练怎么走

```bash
uv run python scripts/bank.py coach --target IMO --save   # ① 出本周题单（每周一次，写 data/plan.json）
uv run python scripts/bank.py spar next                   # ② 开卡：复习到期优先，其次周计划；指定题用 spar start A-037
# ③ 合上电脑，纸笔限时攻坚——题卡 data/sessions/<会话>/statement.md 只有题面（含英文原文），绝无答案，可打印
uv run python scripts/bank.py spar hint                   # ④ 卡住 → 回来解锁下一级提示，再独立奋战 15 分钟
uv run python scripts/bank.py spar reveal                 # ⑤ 弹尽粮绝 → 看解法要点，然后合卷复述完整证明
uv run python scripts/bank.py spar finish                 # ⑥ 登记结果（自动建议，可改判），写入 data/attempts.jsonl
uv run python scripts/bank.py review                      # 到期复习一览（spar next 已自动优先复习题）
```

## 2. 四分结果怎么选

`finish` 会按会话事实自动建议，你可以改判——但判定标准只有一套：

| 结果 | 判定标准 | 下次复习 |
| --- | --- | --- |
| `independent_ok` | 没看答案，提示 ≤1 级，限时内独立完成 | 21 天 |
| `hinted_ok` | 没看答案做出来了，但用到第 2/3 级提示，或超时 | 7 天 |
| `solution_reconstructed` | 看了答案，随后**合卷**复述出完整证明 | 3 天 |
| `fail` | 看了答案，复述也没通过（或没做复述） | 2 天 |

自动建议规则：`reveal` 过 → 系统只问一句「合卷复述通过了吗？」通过＝`solution_reconstructed`，否＝`fail`；没看答案、提示 ≤1 级且没超时 → `independent_ok`；其余 → `hinted_ok`。复述通过的标准是不看任何材料写出完整证明——改判可以，自欺没用。

## 3. 卡点标签怎么选

`finish` 时五选一（`fail` / `solution_reconstructed` 必选，做出来了可留空），选你**最早**卡住的环节：

| 标签 | 症状 |
| --- | --- |
| 建模 | 题读了几遍仍不知从何下手，翻不成数学对象和条件 |
| 识别结构 | 模型建起来了，但没认出该用的结构/方法（看提示 1 秒懂） |
| 关键引理 | 方向对了，卡在中间某个关键命题绕不过去 |
| 技术执行 | 思路完整，但计算、放缩、构造在细节处执行不动或出错 |
| 证明表达 | 心里「会了」，落笔写不成严谨证明 |

## 4. fail 之后的学习周期

一次 fail 不是终点，是一组安排的起点：

- **当天**：看解法 → 合卷复述 → 记卡点（这一步就是 `solution_reconstructed` / `fail` 的判定现场）；
- **+2 天**：做一道近迁移变式（教练指定题号，`spar start <变式ID> --mode variant`），检验能否重建刚学的方法；
- **+2/+3 天**：原题在 review 队列到期（`fail` 2 天、复述通过 3 天），`spar next` 弹出，从零重做——这是短间隔重建检查；
- **长期提取**：由后续复习周期自动检验——重做仍靠提示（`hinted_ok`）7 天后再弹，独立完成（`independent_ok`）21 天后再验，连续 2 次独立完成毕业；
- **+10–14 天**：混排环境里做一道表面不同、方法相同的远迁移题，检验会不会**选**方法。

变式与远迁移题由教练从相似边台账（`data/similar/edges.jsonl`）里挑，你只管打。变式日若原题恰好也到期，先用 `spar start` 打变式，原题留给之后的 `spar next`。

## 5. 纪律是默认值，不是墙

- 限时：★1≤15，★2≤25，★3≤40，★4≤80，★5≤120 分钟；
- 每解锁一级提示，再独立奋战 15 分钟才碰下一级；跳级＝浪费一道好题；
- 系统**绝不阻止**你提前 hint / reveal——但会打上 `early` 标记进日志。early 多不是罪过，它是教练诊断你「何时该求助」的数据。

## 6. 复习与毕业

复习时从零重做，不先看提示。同一题**连续 2 次 `independent_ok`** 即毕业，永久退出复习队列——`review` 会单列「🎓 本次毕业」名单。
