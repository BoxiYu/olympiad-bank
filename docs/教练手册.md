# 教练手册

题库不只是档案，是训练系统。完整闭环：**定目标 → 出周计划 → 限时攻坚（提示阶梯纪律）→ 记录 → 间隔复习**。

## 1. 定目标，出周计划

```bash
python3 scripts/bank.py coach --target AIME --weeks 4 --n 10   # 目标赛事见 plan 配比表
python3 scripts/bank.py coach --target CMO --seed 2            # 换 seed 换一套
```

计划按目标赛事的星级配比 + 四板块轮转生成，自动跳过已做过的题，并在结尾附上当前复习队列。

## 2. 攻坚纪律（核心）

- **限时独立攻坚**：★1≤15min，★2≤25min，★3≤40min，★4≤80min，★5≤120min。限时内不看任何提示。
- **提示阶梯**：每道 ISL 级题目文件末尾有三级提示——
  - 提示 1（方向）：只指出该往哪看，不给结构；
  - 提示 2（关键结构）：给出核心引理/模型，不给推理；
  - 提示 3（临门一脚）：给到差最后一步。
  卡住时**逐级**解锁，每解一级再独立奋战 15 分钟。跳级＝浪费一道好题。
- **看答案的时机**：提示 3 之后仍无进展，或超时 2 倍——看解法要点，然后**合上文件复述完整证明**。

## 3. 记录

每题无论成败都要记：

```bash
python3 scripts/bank.py log --id C-035 --result ok            # 独立做出
python3 scripts/bank.py log --id N-039 --result hard --hints 2  # 用到第 2 级提示
python3 scripts/bank.py log --id A-039 --result fail --hints 3 --note "阈值分层没想到"
```

判定标准：`ok`＝限时内独立完成（提示 ≤1 级）；`hard`＝用了 2-3 级提示或超时完成；`fail`＝看了要点才懂。

## 4. 间隔复习

```bash
python3 scripts/bank.py review
```

fail 隔 2 天、hard 隔 7 天、ok 隔 21 天进入队列。复习时**从零重做**，不先看提示；连续两次 ok 即可从循环中毕业（第二次 ok 后 21 天再冒出来一次，届时秒杀即毕业）。

## 5. 教练观（为什么这样设计）

- 提示阶梯模拟真教练的「递进式点拨」：先救方向，再救结构，最后救细节——最大化每道题的训练价值。
- 限时表按赛制标定：AIME 单题均时 ≈12min，但训练题偏难一档，故上浮；CMO/IMO 单题 90-120min 是实战节奏。
- `--hints` 记录是诊断金矿：某板块 hints 均值高 ⇒ 该板块的「结构识别」环节薄弱，下轮计划应加该板块 ★-1 档的题补基本功。
- 长期数据够了以后（≥50 条记录），可让教练（Claude）读 data/attempts.jsonl 出诊断报告与自适应计划。
